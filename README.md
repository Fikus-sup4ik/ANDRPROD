# ANDRPROD 3.0

Единый центр управления онлайн-плагинами и поиска источников для Lampa.

## Установка

Добавьте в Lampa как источник плагина этот URL:

`https://raw.githubusercontent.com/Fikus-sup4ik/ANDRPROD/main/ANDRPROD-3.0.js`

## Возможности

- Каталог обнаруженных онлайн-плагинов и их источников.
- Единый экран поиска из карточки фильма или сериала.
- Ручной и автоматический режимы поиска.
- Режим «Лучший выбор» на основе доступных метаданных результата.
- Фильтры качества, типа контента, избранного и плагина.
- Сохранение настроек, избранного и приоритетов в хранилище Lampa.
- Публичный API `window.ANDRPROD_API` для регистрации адаптеров и интеграций.

## Совместимость и ограничения

Плагин рассчитан на Lampa 1.x / 2.x / 3.x и использует API самой Lampa. Возможности программного поиска зависят от того, предоставляет ли установленный сторонний плагин доступный API. Если такого API нет, ANDRPROD показывает честный резервный пункт и предлагает открыть оригинальную кнопку плагина, а не выдумывает результаты.
