# ANDRPROD v4.0.0 — Единый центр онлайн-источников для Lampa

Автономный ES5-плагин для медиаплеера [Lampa](https://github.com/yumata/lampa-source), объединяющий подтверждённые онлайн-кинотеатры в единой кнопке внутри карточки фильма и сериала, с поддержкой реального поиска, фильтрации по достоверным характеристикам, алгоритма «Лучший выбор» и встроенной диагностики.

---

## 1. Установка и настройка в Lampa

### Требования к размещению файла (важно против ошибки «Не удалось проверить работоспособность плагина»)
1. Разместите `Andrprod.js` на хостинге, который отдаёт **сырой JavaScript** с заголовками CORS — например, **GitHub Pages** (`https://raw.githubusercontent.com/Fikus-sup4ik/ANDRPROD/main/Andrprod.js`) или прямую ссылку `https://raw.githubusercontent.com/Fikus-sup4ik/ANDRPROD/main/Andrprod.js`.
2. **Не используйте** HTML-ссылку вида `https://github.com/.../blob/main/Andrprod.js` — Lampa получит HTML вместо JS и выдаст ошибку проверки.
3. Если Lampa открыта по **HTTPS**, ссылка на `Andrprod.js` также должна быть **HTTPS** (иначе браузер/WebView телевизора заблокирует загрузку из-за Mixed Content).

### Шаги установки
1. Откройте Lampa → **Настройки** → **Расширения** → **Добавить плагин**.
2. Введите прямую HTTPS-ссылку на `Andrprod.js` и подтвердите.
3. Перезапустите Lampa.
4. Откройте **Настройки → ANDRPROD → Диагностика** и убедитесь, что:
   * Статус плагина: `Загружен (v4.0.0)`
   * Компоненты `(hub / search)`: `OK / OK`
   * Интеграция с карточкой фильма: `Активна`

### Настройка
* **Настройки → ANDRPROD → Режим единого поиска:**
  * `Ручной поиск` — вы сами выбираете, по каким установленным онлайн-плагинам искать.
  * `Автоматический поиск` — поиск запускается сразу по всем подтверждённым онлайн-плагинам.
  * `Лучший выбор` — дополнительно анализирует реальные результаты и выделяет оптимальный вариант.
* **Тайм-аут поиска:** `3 / 6 / 9 / 12 сек` (изолирует медленные или недоступные серверы).
* **Фильтры (сохраняются в `Lampa.Storage`):** `2160p / 4K`, `1080p`, `720p`, `SD`, `Неизвестно`, `HDR`, `Dolby Vision`, `С переводом`, `С субтитрами`, а также приоритеты и избранные источники.

## 2. Подробный отчёт об ошибках старых версий (Аудит)

| Версия | Найденная проблема | Фактическое влияние | Исправление в v4.0.0 |
| :--- | :--- | :--- | :--- |
| v1.0–v3.0 | Преждевременный флаг `window.andrprod_plugin_loaded = true` в самом начале скрипта | При любой ошибке ранней инициализации плагин считался загруженным и блокировал повторный запуск | Флаг `window.andrprod_plugin_ready = true` выставляется **только после** подтверждённой регистрации компонентов `andrprod_hub` и `andrprod_search` |
| v1.0–v3.0 | Отсутствовала регистрация манифеста `Lampa.Manifest.plugins` и проверка `window.Lampa` | При ранней загрузке скрипта до готовности Lampa возникал `ReferenceError`, а менеджер расширений не видел метаданные плагина | Добавлен `bootstrap()` с безопасным ожиданием `window.Lampa` и регистрацией `Lampa.Manifest.plugins = manifest` |
| v1.0–v3.0 | Пустые блоки `catch (err) {}` в инициализации и сетевых запросах | Скрывали реальные причины сбоев, делая отладку на ТВ невозможной | Все перехваты пишут модуль и причину в `Diagnostics.logError()` и `console.error` |
| v2.0–v3.0 | Автоматическое добавление всех неизвестных расширений и `TorrServer` | Темы, субтитры, рейтинги и торрент-модули засоряли каталог онлайн-источников | Введён строгий белый список онлайн-кинотеатров (`ONLINE_PLUGIN_WHITELIST`) и чёрный список (`NON_ONLINE_BLACKLIST`); прочие расширения видны только в «Диагностике» |
| v3.0–v3.1 | Нет отмены устаревших поисковых запросов при новом поиске или закрытии экрана | Поздние ответы могли дописываться в уже закрытый экран или новый поиск | В `UnifiedSearchEngine` добавлены `activeSessionId`, трекинг `Lampa.Reguest` и `cancelActiveSearch()` с вызовом `net.clear()` |
| v3.1 | Немедленный запуск без подтверждения параметров потока | Пользователь мог случайно запустить неподходящий вариант | Добавлен диалог `confirmAndLaunch()` с показом источника, качества, HDR/DV, перевода и субтитров |

| **Online Mod** (`nb557`) | **Частично поддерживается** | Чтение текущего балансира из `Lampa.Storage` (`online_mod_balanser`, read-only) + запуск через штатную кнопку карточки | Внутренний список балансиров скрыт внутри IIFE плагина [nb557/plugins](https://github.com/nb557/plugins) |
| **Lumio, Showy, HDRezka, KinoPub, Filmix, Kodik, Alloha, Collaps, VideoCDN, Ashdi, Eneyida, UAKino** | **Частично поддерживается** | Запуск через штатную кнопку плагина в карточке фильма/сериала | Нет публичного межплагинного JS-API поиска; при нажатии открывается оригинальный экран плагина |
| **Темы, интерфейс, субтитры, рейтинги, TorrServer, неизвестные расширения** | **Не поддерживается** (исключены из каталога) | Не подключаются к каталогу онлайн-кинотеатров | Отображаются только в разделе **«Диагностика»** с указанием причины фильтрации |

## 4. Описание архитектуры `Andrprod.js`

1. **`Diagnostics`** — учёт статуса загрузки, регистрации манифеста и компонентов, отфильтрованных расширений, времени и числа результатов последнего поиска, журнала ошибок.
2. **`BrandIcons`** — прозрачный SVG-логотип `ANDRPROD` (без фона и рамки, увеличен специально для ТВ) и генератор иконок для плагинов.
3. **`StorageManager`** — безопасное сохранение настроек, режимов, приоритетов, избранного, выбора плагинов в ручном поиске и фильтров в `Lampa.Storage`.
4. **`TitleResolver`** — разделяет поля фильма (`title` / `original_title` / `release_date`) и сериала (`name` / `original_name` / `first_air_date`), строит дедуплицированные варианты запросов и никогда не блокирует поиск при отсутствии английского названия.
5. **`PluginAdapterEngine` + `SourceRegistry`** — белый список онлайн-кинотеатров и адаптеры получения реальных источников.
6. **`FilterEngine` + `BestChoiceEngine`** — фильтрация строго по реальным характеристикам (`2160p/4K`, `1080p`, `720p`, `SD`, `Неизвестно`, `HDR`, `Dolby Vision`, перевод, субтитры) и взвешенная оценка лучшего результата с учётом равноценных кандидатов.
7. **`UnifiedSearchEngine`** — независимый поиск по плагинам с отменой устаревших запросов (`activeSessionId` + `net.clear()`), изоляцией ошибок, дедупликацией по URL потока и ручным подтверждением воспроизведения (`confirmAndLaunch`).
8. **`CardIntegration`, `AndrprodSearchComponent`, `AndrprodHubComponent`, `SettingsIntegration`** — встраивание кнопки только в карточку фильма/сериала, экраны поиска, каталога и диагностики с управлением пультом ТВ (`Lampa.Controller`).

## 6. План проверки на реальных устройствах (Android TV, Tizen, webOS)

Поскольку автоматические тесты выполнялись в изолированной Node.js-среде с эмуляцией `Lampa` API, перед полноценным использованием рекомендуется пройти чек-лист на целевых устройствах:

1. **Android TV (Lampa APK / Android WebView):**
   * Добавить HTTPS-ссылку `Andrprod.js` в **Настройки → Расширения**, перезапустить приложение.
   * Проверить **Настройки → ANDRPROD → Диагностика** (отсутствие ошибок, корректный список онлайн-плагинов).
   * Открыть фильм на русском, фильм без английского названия и многосезонный сериал — убедиться, что крупная кнопка `ANDRPROD` чётко читается с 2–3 метров и не обрезается при фокусе D-pad.
   * Запустить поиск, проверить подтверждение запуска и реальное воспроизведение в плеере.
2. **Samsung Tizen (Smart TV):**
   * Проверить, что WebView Tizen (ES5) загружает скрипт без синтаксических ошибок (в коде нет `const`/`let`/`=>`/шаблонных строк).
   * Проверить клавишу `Return/Back` на пульте: возврат со страницы плагина на главную ANDRPROD и выход из экрана поиска в карточку фильма.
3. **LG webOS (MSX / WebApp):**
   * Проверить отсутствие проблем с CORS/Mixed Content при загрузке `Andrprod.js` и опросе сервера Lampac/BWA.
   * Проверить быстрый запуск нового поиска или выход `Back` во время активного поиска — убедиться, что устаревшие запросы корректно отменяются и интерфейс не подтормаживает.
